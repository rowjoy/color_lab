# TintAtlas improvement backlog

This folder records work that cannot be completed truthfully with the current
code, evidence, hardware, accounts, people, or user-authorized scope.

## Rule

Whenever implementation reaches a blocked or externally owned requirement:

1. Do not invent evidence, data, people, measurements, credentials, or a pass.
2. Keep the safe production fallback enabled.
3. Add or update a detailed note in this folder with:
   - the exact incomplete requirement;
   - why it cannot be completed now;
   - current safe behavior;
   - required inputs/owner;
   - verification and acceptance criteria;
   - files likely affected when work resumes.
4. Link the note from the relevant plan/release ledger when that plan closes.
5. Remove or mark an item complete only after real evidence is verified.
