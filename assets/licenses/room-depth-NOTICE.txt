This model predicts relative inverse depth, not object classes or distances in
meters. Color Lab uses robust wall-plane estimation to exclude nearer objects
from automatic Wall ownership. Whole-photo bilinear resizing to 256x256 is a
Color Lab preprocessing choice, unlike the upstream Android demo's center crop.
RGB normalization follows the upstream mobile demo: (channel - 115) / 58.
Depth, masks, and processing remain on-device. No runtime model download occurs.
